# Dhanbad Food Guide

A practical local food and dining publication operated by Vishhal Family Restaurant, Dhanbad, Jharkhand.

## Website
When GitHub Pages is enabled for this public repository, the project site will be:
https://vishhalfamilyrestaurant-ai.github.io/VFRblog/

## Publishing
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then Save.

GitHub Free Pages requires a public repository. The site itself is public on the internet. Do not add secrets, credentials, or private information to this repository.

## Editorial disclosure
This publication is operated by Vishhal Family Restaurant. It is not an independent third-party review platform. Articles aim to provide useful, original information about food, dining and local food culture.
